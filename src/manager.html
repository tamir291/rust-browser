Прокси применяется ко всем сайтам профиля. Для отдельных сайтов можно выделить профиль. Используй IP-адрес локального прокси VPN-клиента.

Дополнительные настройки

DNS и маршруты

DNS сайтов идёт через узел. Для имени самого узла используется отдельный зашифрованный bootstrap. Строгая маршрутизация действует во время работы TUN.

Установленные модули

    Модули загружаются из папки modules текущего профиля. Поддерживаются манифесты команд открытия сайтов.

    Оформление

    Конфигурация JSON

    Файл preferences.json хранит настройки профиля. В файле нет истории, cookies, паролей или ссылок подписки.
